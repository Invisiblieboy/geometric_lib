# circle.py area() 

## `area(int|float)`

Находит площадь круга 

**Параметры**

| Имя | Тип | Описание |
|-----|-----|----------|
| `r` | `int\float` | радиус круга |

**Возвращает:** `float` — площадь круга.

**Пример вызова**

```python
r = 3
result = area(r)
print(result)  # 28.26
```
